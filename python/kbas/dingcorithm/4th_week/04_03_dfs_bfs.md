# dfs & bfs 의 사전적 정의

## dfs (깊이 우선) : Depth First Search

> 자료의 검색, 트리나 그래프를 탐색하는 방법으로서, 한 노르르 시작하여 인접한 다른 노드를 재귀적으로 탐색하고, **끝까지 탐색하면** 다시 위로 올라와 다음을 탐색하며 검색한다.

## bfs (너비 우선) : Depth First Search

> 한 노드를 시작으로 인접한 모든 정점들을 **우선 방문**하는 방법. 더 이상 방문하지 않은 정점이 없을 때까지 방문하지 않은 모든 정점들에 대해서도 넓이 우선 검색을 적용한다.

# dfs & bfs를 왜 배우나?

- 정렬된 데이터를 이분 탐색하는 것처럼 아주 효율적인, 시간복잡도를 획기적으로 줄여주는 방법이 있는 반면에, 모든 경우의 수를 **전부 탐색해야 하는** 경우도 있다.
- dfs와 bfs는 그 탐색하는 순서에서 차이가 있다. dfs는 끝까지 파고들고, bfs는 갈라진 모든 경우의 수를 탐색해보고 오는 것이 차이다.

# 두 탐색 방법의 공간 차이

## dfs의 공간

> DFS는 끝까지 파고드는 것이라, 그래프의 최대 깊이 만큼의 공간을 요구한다. 왜냐? 모든 깊이를 탐색한 정보들을 저장해야하기 때문이다. 반면에 그런 만큼 공간은 깊이만 신경 쓰면 되는 것이 된다.
> 따라서 공간을 적게 쓴다. 그러나 최단 경로를 탐색하기 쉽지 않다.

## bfs의 공간

> 반대로, BFS응 깊이 위주고 아니라 너비 위주다. 그래서 최단 경로를 쉽게 찾을 수 있다. 자잘한 모든 선택지들 먼저 보고 탐색을 진행하기 때문이다.
> 다만, 모든 분기점들을 다 보고 와야하니깐 공간을 많이 차지한다.

# 구현

## DFS 로 구현해보기 - 재귀함수

갈 수 있는 만큼 **계속해서** 탐색하다가 더이상 **갈 수 없게 되면** 다른 방향으로 다시 탐색하는 구조.
예시를 들어보자.

1. 노드를 방문하고 **깊이 우선으로 인접한** 노드를 방문한다.
2. 또 그 노드를 방문해서 **깊이 우선으로 인접한** 노드를 방문한다.
3. **만약 끝에** 도달하면 돌아온다.

반복하다, 갈 수 없으면,,, 탈출 조건,,,<br/>
그렇다. 바로 **재귀함수**를 통해서 DFS 를 구현할 수 있는 것이다.

---

DFS 의 반복 방식은 방문하지 않은 노드를 계쏙해서 찾아가면 된다.

즉, DFS라는 함수가 있다고 치자.<br/>
DFS(node) = node + DFS(node와 인전하지 않는 다른 node)로 반복한다.

그런데, 방문하지 않았다는 조건을 어떻게 알까?<br/>
**다 기록해놓아야 한다.**
이를 위해서 `visited`ㄹ라는 배열에 방문한 노드를 기록해두면 될 것이다.

### 순서 정리

1. 루트 노트부터 시작한다.
2. 현재 방문한 노드를 visited 에 추가한다.
3. 현재 방문한 노드와 인접한 노드 중 방문하지 않은 노드에 방문한다.
4. 2번부터 시작한다.

### 실제 구현

그래프를 예씨로 삼아서 인접 리스트 방식으로 표현했다.

```python
graph = {
    1: [2, 5, 3],
    2: [1, 3],
    3: [2, 4],
    4: [3],
    5: [1, 6, 8],
    6: [5, 7],
    8: [5],
    9: [1, 10],
    10: [9]
}

visited = [] # 방문한 걸 저장하기 위한 배열

cur_node = 1 # 1. 우선 탐색 시작 노드를 1로 잡겠다.
visited.add(cur_node) # 2.  현재 방문한 노드인 1을 visited 에 추가한다. visited -> [1]
cur_node = 2 # 3. 인접한 노드들인 [2,5,9] 중 방문하지 않는 것들은 [2,5,9] 이다. 2에 방문한다.
visited.add(cur_node) # 4. 현재 방문한 노드인 2를 visited 에 추가한다. visited -> [1, 2]
cur_node = 3 # 5. 인접한 노드들인 [1,3] 중 방문하지 않는 것들은 [3] 이다. 3에 방문한다.
visited.add(cur_node) # 6. 현재 방문한 노드인 3을 visited 에 추가한다. visited -> [1, 2, 3]
cur_node = 4 # 7. 인접한 노드들인 [2, 4] 중 방문하지 않는 것들은 [4] 이다. 4에 방문한다.
visited.add(cur_node) # 8. 현재 방문한 노드인 4를 visited 에 추가한다. visited -> [1, 2, 3, 4]
# 9. 4와 인접한 노드는 3이다. 근데 3은 방문했다. 7번 순서로 돌아간다.
# 7. 인접한 노드들인 [2, 4] 중 방문하지 않는 것들은 없다. 5번 순서로 돌아간다.
# 5. 인접한 노드들인 [1, 3] 중 방문하지 않는 것들은 없다. 3번 순서로 돌아간다.
# 3. 인접한 노드들인 [2, 5, 9] 중 방문하지 않는 것들은 [5,9] 이다. 5에 방문한다.
# 쭉쭉쭉 ...
```

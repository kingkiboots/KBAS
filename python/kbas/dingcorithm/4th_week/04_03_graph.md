# 그래프

## 그래프란?

> 연결되어 있는 정점과 정점 간의 관계를 표현할 수 있는 자료구조

## 그래프 개념

트리를 배우면서 배운 "비선형 구조", 이는 표현에 초점이 맞춰져 있다.
그에 반해, 선형 구조는 자료를 저장하고 꺼내는 것에 초점이 맞춰져 있다.

> 그러니깐, 그래프란 **연결 관계에 초점**이 맞춰져 있는 것이다.

## 그래프 용어

그래프에서 사용된느 용어들을 정해자라면 다음과 같다.

- 노드(Node): 연결 관계를 가진 각 데이터를 의미한다. 정점(Vertex)이라고도 한다.
- 간선(Edge): 노드 간의 관계를 표시한 선
- 인접 노드(Adjacent Node): 간선으로 직접 연결된 노드(또는 정점)

## 그래프 예시

```
          원이 - 리브
           |
    제나 - 기현
```

기현은 연결 관계를 가진 데이터, **노드**이다.
기현과 제나는 **간선**으로 연결되어 있다.
기현과 원이는 **인접 노드**다.

## 그래프 종류

그래프 종류에는 유방향 그래프와 무방향 그래프 두가지가 있다.<br/>
그러나 이 강의에서는 **무방향 그래프**에 대해서만 배울 것이다.

유방향 그래프(Directed Graph): 방향이 있는 간선을 갖습니다. 간선은 단방향 관계를 나타내며, 각 간선은 한 방향으로만 진행할 수 있다.
무항향 그래프(Undirected Graph)는 방향이 없는 간선을 갖는다.

- 유방향 그래프

```
          원이 ->  리브 <- 미나미
           ^       ^
           |       |
    제나 -> 기현 -> 메이
```

- 무방향 그래프: 연결되어있는 것만 있지, 방향에 대한 정보는 없다.

```
          원이 - 리브 - 미나미
           |     |
    제나 - 기현 - 메이
```

## 그래프 표현 방법

그래프를 컴퓨터에서 표현하는 방법에는 두 가지가 있다.

1. 인접행렬(Adjacnecy Matrix): 2차원 배열로 그래프의 연결 관계를 표현
2. 인접리스트(Adjacnecy List): 링크드 리스트로 그래프의 연결 관계를 표현

더 쉽게 표기하기 위해 각 노드들에 번호를 매겨보자.
제나를 0, 기현을 1, 원이를 2, 리브를 3이라고 하겠다.

```
        2 - 3
        |
    0 - 1
```

### 1. 인접행렬

아래와 같이 0번 노드가 1번 노드와 연결되어있다는 등의 관계를 2차원 배열로 표현할 수 있다.

```python
graph = [
    [False, True, False, False],
    [True, False, True, False],
    [False, True, False, True],
    [False, False, True, False],
]
```

이는 무언가를 조회하는 데에는 시간복잡도가 O(1)이다.
ex) graph[1][2]

### 2. 인접리스트

아뢔 같이 모든 노드에 연결되 노드에 대한 정보를 차례대로 저장한다.

```python
graph = {
    0: [1],
    1: [0, 2],
    2: [1, 3],
    3: [2]
}
```

근데 얘는 무언가를 조회할 때 시간복잡도가 O(N)이 걸린다.

## 정리

> 시간 vs 공간

### 시간

- 인접 행렬은 O(1)
- 인접 리스트는 O(N)

### 공간

- 인접행렬은 시간은 많이 절약하지만, 공간을 N^2 만큼 차지 한다.
- 인접 리스트는 **현재 노드들의 개수 \* 간선의 개수** 만큼만 차지한다. 아무리 커져도 제곱만큼 커지지는 않는다. 아무리 해봤다 O(N)정도다 라고 생각하면 된다.

> 확보하고자 하는 것에 따라 알고리즘을 선택하면 된다.

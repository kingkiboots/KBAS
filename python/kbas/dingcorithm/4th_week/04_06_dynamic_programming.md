# Dynamic Programming (동적 계획법)

## 피보나치 수열 - 재귀함수

동적 계획법에 대해 더 설명하기 전에 피보나치 수열에 대해 알고 가면 DP의 필요성을 더욱 절실히 느낄 것이다.<br/>

### 피보나치 수열이란?

> 수학에서, 피보나치 수는 첫째 및 둘째 항이 1이며, 그 뒤의 모든 상은 바로 앞 두 항의 합인 수열이다. 처음 여섯 항은 각각 1, 1, 2, 3, 5, 8 이다.

### 공식

즉, n번째 피보나치 수를 Fibo(n)이라 표현한다면,<br/>
Fibo(1)은 1이고 Fibo(2)도 1이다.<br/>

Fibo(3) 부터는 이전 값과 그 이전 값의 합이다.<br/>
즉, Fibo(3) = Fibo(1) + Fibo(2) 이다. (1 + 1 = 2)

쭉쭉 나열해보자면,

- Fibo(4) = Fibo(3) + Fibo(2) = 2 + 1 = 3
- Fibo(5) = Fibo(4) + Fibo(3) = 3 + 2 = 5
- Fibo(6) = Fibo(5) + Fibo(4) = 5 + 3 = 8
- ...
- Fibo(n) = Fibo(n - 1) + Fibo(n - 2)

이렇게 된다.

> 그리고 이건 재귀함수로 풀 수 있다.

## 동적 계획법

### 탄생 배경

가장 효율적인 방법 알고 싶다.
각각의 목적지로 이동하는 방법은 지하철, 버스, 따릉이, 공유 킥보드가 있다.

그래서 다음과 같이 매일 실험했다.

1일: 지하철(15분) - 지하철(20분) - 지하철(3분)
2일: 지하철(15분) - 지하철(20분) - 버스(5분)
3일: 지하철(15분) - 지하철(20분) - 따릉이(4분)
4일: 지하철(15분) - 지하철(20분) - 공유 킥보드(6분)
5일: 지하철(15분) - 버스(20분) - 지하철(3분)
6일: 지하철(15분) - 버스(20분) - 버스(5분)
......

근데 굳이 이렇게 직접 다녀야 아나?

각 구감나다 수단이 얼마나 걸리는지 알기만 하면 되니깐 어디다가 적어놓기만 하면 또 같은 실험을 하지 않아도 되지 않을까?

이런 반복되는 구조 속에서 효율을 찾기 위해 동적 계획법(Dynamic Programming)이 탄생한 것이다.

### 사전적 정의

> 동적 계획법(Dynamic Programming)이란, 복잡한 무넺를 간단한 여러 개의 무넺로 나누어 푸는 방법을 말한다. 이것은 부분 문제 반복과 최적 부분 구조를 가지고 있는 알고리즘을 일반적인 방법에 비해 더욱 적은 시간 내에 풀 때 사용한다. \[위키백과\]

### 개념

동적 계획법은 여러 개의 하위 문제를 풀고 그 결과를 기록하고 이용해 문제를 해결하는 알고리즘이다.

#### 하위문제?

> 큰 문제를 일정한 형태로 비슷하게 만들어서 작은 문제로 쪼갤 수 있다면, 이 작은 문제들로 큰 문제를 조금씩 해소해갈 수 있다.<br/>
> 예를 들어, 재귀함수를 풀어나갈 때 함수의 수식화를 시켰던 것처럼 말이다. `F(string) = F(string[1:n-2])`라고 수식을 정의했던 것처럼 문제를 쪼개서 정의할 수 있다면 동적 계획법을 쓸 수 있다.<br/>
> 차이점이라고 한다면 **그 결과를 기록하고 이용한다**는 점이다.

#### 용어 정리

- 메모이제이션(Memoization): 결과를 기록하는 것
- 겹치는 부분 문제(Overlapping Subproblem): 문제를 쪼갤 수 있는 구조

> 즉, **겹치는 부분 문제일 경우 동적 계획법을 사용**하면 되는데,<br/>
> 이 때 사용하는 방법은 메모이제이션을 이용한다고 보면 된다.

## 적용 사례

React 를 하다보면 useCallback, useMemo, memo 이런 hook 이나 hoc를 쓸 떄가 있다.<br/>
무거운 연산의 결과를 메모리에 저장하여 불필요하고 무거운 연산을 반복하게 하지 않는 `Memoization` 기법이다.<br/>
그리고 이 메모이징이 바로 DP의 기법 중 하나이다.<br/>
DP, 그것은 Dynamic이 주는 어감처럼 어려운 것이 아니라, 결과값을 어딘가에다가 저장을 해두고, 이를 꺼내다 쓰는 것이다.

## 피보나치 수열 - 동적 계획법

재귀 함수로 피보나치 수열을 구현했을 때,
계속 똑같은 문제를 다시 푸는 바람에 목표를 달성하지 못했다. 리커션맥스!

이번에는, 새로 배운 동적 계획법의 메모이제이션이라는 방법을 사용해 해결해볼 것이다.

### 구현의 방법

1. 메모용 데이터를 만든다. 처음 값인 Fibo(1), Fibo(2)는 각각 1씩 넣어서 저장한다.
2. Fibo(n) 을 구할 떄 만약 메모에 그 값이 있다면 바로 반환한다.
3. Fibo(n) 을 처음 구했다면 메모에 그 값을 기록한다.
